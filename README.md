# AsterBalls

A fast-paced arcade shooter built entirely in vanilla JavaScript and HTML Canvas.

Defend the center against waves of colorful enemies that grow faster and stronger over time. Take down massive bosses every 20 seconds for bonus points. How long can you survive?

## Play

[rramboer.github.io/asterballs](https://rramboer.github.io/asterballs)

## Controls

- **Desktop:** Click to shoot
- **Mobile:** Tap to shoot

## Features

- Progressive difficulty with ramping spawn rates and enemy speed
- Boss fights every 20 seconds with HP bars and big rewards
- Procedural sound effects via Web Audio API
- Particle explosions, screen shake, and floating score popups
- Persistent high score with new-best celebration
- Starfield background with twinkling stars
- Fully responsive with window resize support
- No dependencies beyond GSAP for animations

## Built With

- Vanilla JavaScript
- HTML5 Canvas
- [GSAP](https://greensock.com/gsap/) for tweening
- Web Audio API for sound
